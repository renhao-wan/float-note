# Blink 国际化（i18n）设计文档

## 概述

为 Blink 应用添加国际化支持，支持中文和英文界面，默认中文。用户可以在设置面板中切换语言，切换后立即生效，无需重启应用。

## 目标

1. 支持中文和英文两种语言
2. 默认语言为中文
3. 在设置面板的通用设置中添加语言切换
4. 语言切换即时生效
5. 语言偏好持久化到 AppConfig
6. 覆盖所有 UI 文本、提示信息和默认笔记模板

## 技术方案

### 技术栈

- **react-i18next**：React 国际化框架
- **i18next**：核心国际化库
- **i18next-browser-languagedetector**：浏览器语言检测

### 架构设计

```
┌─────────────────────────────────────────────┐
│ 用户界面                                     │
│  ┌─────────────┐  ┌─────────────┐           │
│  │ 设置面板    │  │ 其他组件    │           │
│  │ (语言切换)  │  │ (使用 t())  │           │
│  └──────┬──────┘  └──────┬──────┘           │
│         │                │                  │
│         ▼                ▼                  │
│  ┌─────────────────────────────────────┐   │
│  │ react-i18next                       │   │
│  │  - useTranslation() hook            │   │
│  │  - t() 函数                         │   │
│  └──────────────────┬──────────────────┘   │
│                     │                      │
│                     ▼                      │
│  ┌─────────────────────────────────────┐   │
│  │ i18next 核心                        │   │
│  │  - 语言检测                         │   │
│  │  - 翻译加载                         │   │
│  │  - 回退机制                         │   │
│  └──────────────────┬──────────────────┘   │
│                     │                      │
│         ┌───────────┴───────────┐          │
│         ▼                       ▼          │
│  ┌─────────────┐        ┌─────────────┐   │
│  │ zh.json     │        │ en.json     │   │
│  │ (中文翻译)  │        │ (英文翻译)  │   │
│  └─────────────┘        └─────────────┘   │
└─────────────────────────────────────────────┘
```

### 数据流

```
用户选择语言
    ↓
更新 AppConfig.language
    ↓
保存到后端 (config-api.updateConfig)
    ↓
触发 i18next.changeLanguage()
    ↓
react-i18next 自动更新所有组件
    ↓
UI 文本切换到新语言
```

## 配置扩展

### AppConfig 新增字段

```typescript
export interface AppConfig {
  // ... 现有字段
  language: 'zh' | 'en';  // 语言偏好，默认 'zh'
}
```

### 默认配置

```typescript
export const defaultConfig: AppConfig = {
  // ... 现有默认值
  language: 'zh',
};
```

### 配置迁移

使用现有的 `migrateConfig` 函数确保旧配置兼容：

```typescript
export const migrateConfig = (config: any): AppConfig => {
  return {
    ...defaultConfig,
    ...config,
    language: config.language || 'zh',  // 未设置则默认中文
    // ... 其他迁移逻辑
  };
};
```

   ```bash
   pnpm add react-i18next i18next i18next-browser-languagedetector
   ```
